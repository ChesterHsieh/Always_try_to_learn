# 路線圖與里程碑

> 起點：2026-07-31｜投入強度：12 h/週｜主線 289 h ≈ **24 週**｜全樹 393 h ≈ 33 週

---

## 一、最終目標（逆推）

```
🎯 在 Isaac Sim 模擬環境中訓練，然後操作一台真實機械手臂
                            ▲
                            │ 需要
        ┌───────────────────┼───────────────────┐
        │                   │                   │
   sim-to-real          高保真模擬            真實硬體介面
   （A8-6）            （A8-1~A8-5）        （A4-5, A10-1）
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │ 全部需要
                    ┌───────┴────────┐
                    │  ros2_control  │  ← 模擬與真機的共同抽象層
                    │    (A4-1)      │
                    └───────┬────────┘
                            │ 需要
                    ┌───────┴────────┐
                    │  URDF + tf2    │  ← 機器人的空間表示
                    │ (A2-1, A1-14)  │
                    └───────┬────────┘
                            │ 需要
                    ┌───────┴────────────┐
                    │  ROS 2 通訊核心      │  ← 一切的地基
                    │  (第一章 17 節點)    │
                    └────────────────────┘
```

**關鍵洞察**：`ros2_control` 是這條路線的樞紐。
它讓「模擬中的手臂」與「真實的手臂」對上層軟體長得一模一樣。
因此同一套 MoveIt 設定、同一個 policy，可以在 Gazebo → Isaac Sim → 真機之間搬移而不改 code。

## 三、時間分配建議（12 h/週）

```
週一 ~ 週四  各 1.5 h   讀資料 + 小實驗（在技能樹上勾任務）
週六         4 h        整塊時間，做需要連續專注的節點（模擬、除錯）
週日         2 h        寫筆記、整理、規劃下週
```

**節點顆粒度已經對齊這個節奏**：多數節點 3–6 h，可以在 2–4 個晚上完成。
超過 10 h 的節點（A7-1 運動學、A8-5 Isaac Lab、A10-4 Capstone）是刻意的 —
它們是需要沉浸的大關卡。

## 五、進度追蹤

技能樹本身就是追蹤工具：

```bash
open skill-tree/index.html
```

- 每完成一個小任務就勾一格，節點會從 🔒 → 百分比 → ✓
- 全部勾完的節點會發光，並解鎖後續節點（連線變金色）
- 右上角顯示等級、XP、剩餘時數、預估週數
- **進度存在瀏覽器的 localStorage**。定期按「匯出進度」存成 JSON 備份到這個 repo

> 💡 用 `file://` 開啟時 Safari 可能會擋 localStorage。
> 建議 `cd skill-tree && python3 -m http.server 8080`，然後開 `http://localhost:8080`。

## 七、什麼時候該調整這棵樹

樹是活的，這些情況要改：

- **Nav2 在 Lyrical 釋出了** → 2027 年可考慮整體升級到 Lyrical（LTS 到 2031）
- **NVIDIA 恢復 Orin 的 Isaac ROS 支援** → A9 章可改走 JetPack 7 + Jazzy，消除版本分歧
- **你買了特定型號的手臂** → A10 章改成該廠商的 driver 與 URDF
- **你發現某個節點的資源不好** → 直接改 `skill-tree/tree_data.py` 然後 `python3 build.py`

改完記得重新 build，HTML 會重新產生但**進度不會遺失**（進度是以 node id 為 key）。
