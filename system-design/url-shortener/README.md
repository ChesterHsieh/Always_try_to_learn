# URL Shortener 學習樹

Staff 級系統設計面試導向，40 節點 / 120 題 / 84 小時（主線 78 小時）。

- 資料單一來源：`tree_data.py`
- 產物：`url-shortener.html`（單檔自足，無外部依賴）
- 重建：在上層目錄執行 `python3 build.py url-shortener`

## 十章

| 章 | 主題 | 樞紐節點 |
|---|---|---|
| A0 | 四十五分鐘的骨架 | 先寫下 SLO，再畫方塊 |
| A1 | 需求與容量估算 | 用估算否決設計 |
| A2 | 短碼與發號 | 三種發號策略正面對決 |
| A3 | 儲存選型與分片 | 分片鍵與一致性雜湊 |
| A4 | 讀取路徑與快取 | 雪崩、擊穿、穿透 |
| A5 | 重導語意與邊界 | 把每一毫秒落實回去 |
| A6 | 寫入路徑與一致性 | 自訂短碼的競態 |
| A7 | 點擊分析管線 | 精確還是近似 |
| A8 | 可用性與多區 | 多區複製與衝突 |
| A9 | 治理、濫用與收尾 | 從單機講到全球 |
