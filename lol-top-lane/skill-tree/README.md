# 上路回鍋技能樹

給回鍋的英雄聯盟玩家（鐵～銅、每週約 4 小時）的上單學習路徑：
41 個節點、123 題試煉，從補刀一路排到中後期決策與復盤。

## 檔案

| 檔案 | 用途 |
|---|---|
| `tree_data.py` | **資料單一來源**。`META`（設定）、`N`（節點）、`Q`（題庫） |
| `build.py` | 產生器 ＋ 驗證器。驗證不過會 exit 1 |
| `index.template.html` | UI 樣板。唯一注入點是 `/*__TREE_JSON__*/` |
| `lol-top.html` | 產出。單一自足、無外部依賴，可直接開啟或發布 |
| `skill-tree.json` | 副產物，除錯用 |

## 重新產生

```bash
python3 build.py
```

改動一律改 `tree_data.py`，**不要手改 `lol-top.html`**。
配色、章節、稱號、閘門開關等 UI 差異走 `META`，不要改樣板。

## 維護

兵線、經濟換算、換血結算等原理不會。大改版後只需重跑那幾個節點的檢查。
