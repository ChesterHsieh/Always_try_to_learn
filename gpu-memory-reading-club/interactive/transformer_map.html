「K、V 來自 encoder memory M」到底搬了什麼？
① encoder 把整段來源算成 M [5×6]（一次）→ 寫進 HBM → ② 每個 decoder 層用 Wk/Wv 把 M 投影成 cross-K / cross-V（一次）→ 快取在 HBM，大小固定（T_enc 決定） → ③ 算 attention 時 cross-K/V 從 HBM → SRAM → tensor core；decode 每步重讀同一份
所以「來自 M」的搬遷＝一次性算好 cross-K/V 存 HBM、之後每步從 HBM 重讀。關鍵：它不隨生成長度長大——self-attn 的 KV cache 每生一字多一列，cross 永遠只是「來源那幾列」。
